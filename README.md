# MoneyFlow

A polished personal money-management dashboard built with Next.js, React, Recharts and CSS.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Included

- Responsive dark finance dashboard
- Balance, income, expense and savings metrics
- Spending area chart
- Category donut chart
- Recent transactions
- Savings goals
- Add transaction modal
- Responsive mobile navigation
- Toast feedback
- No external database required for the demo UI
